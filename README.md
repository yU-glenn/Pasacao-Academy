# Pasacao Academy Website 🎓

A modern, responsive, and Pasacao Academy website built with HTML5, CSS3, Bootstrap 5, and vanilla JavaScript.

## ✨ Features

### Header
- **Top Bar**: Green strip with quick navigation links (Campus Life, Academic Calendar, Degree Finder, Students, Faculty, Alumni, Apply Now)
- **Main Navigation**: Sticky navbar with logo, school name, center menu (Home, About, Admissions, Academics, Research, Campus Life, News, Contact), search icon, and responsive hamburger menu

### Sections
1. **Hero Section** - Full-width banner with campus image, dark overlay, headline, and CTA buttons
2. **Quick Links** - 8 icon cards (Admissions, Academic Programs, Scholarships, Library, Student Portal, LMS, Registrar, Downloads)
3. **About Section** - Two-column layout with image, history, mission, and feature list
4. **Academic Programs** - 6 program cards (Elementary, Junior High, Senior High, College, Graduate School, Technical-Vocational)
5. **Why Choose Us** - 4 feature cards with icons (Quality Education, Experienced Faculty, Modern Facilities, Student-Centered Learning)
6. **Campus News & Events** - Grid of 6 news cards with images, dates, descriptions, and Read More buttons
7. **Statistics** - Animated counters (Students Enrolled, Faculty Members, Programs Offered, Years of Excellence)
8. **Testimonials** - Bootstrap carousel slider with student/alumni/faculty testimonials
9. **Gallery** - Responsive image grid with hover animations and lightbox
10. **Contact Section** - Google Map, contact form, address, phone, email, office hours
11. **Footer** - Multi-column footer with about, quick links, admissions, academics, student services, social media icons, and copyright

### Technical Features
- ✅ HTML5 Semantic Markup
- ✅ CSS3 Custom Properties
- ✅ Bootstrap 5 Grid & Components
- ✅ Vanilla JavaScript (no jQuery)
- ✅ Font Awesome 6 Icons
- ✅ Google Fonts (Poppins)
- ✅ Responsive Design (Desktop, Tablet, Mobile)
- ✅ Mobile-First Approach
- ✅ Scroll Reveal Animations
- ✅ Smooth Scrolling
- ✅ Animated Counters (Intersection Observer)
- ✅ Gallery Lightbox
- ✅ Sticky Navbar with Shadow
- ✅ Back to Top Button
- ✅ Contact Form Validation
- ✅ SEO-friendly Structure

## 🎨 Design System

| Element | Style |
|---------|-------|
| **Primary Color** | `#006633` (Green) |
| **Accent** | `#004d26` (Dark Green) |
| **Background** | `#ffffff` (White) / `#f8f9fa` (Light Gray) |
| **Font Family** | Poppins |
| **Border Radius** | 12px (cards), 50px (buttons) |
| **Shadows** | Soft layered shadows with green tint on hover |
| **Transitions** | 0.3s ease for all interactive elements |
| **Glassmorphism** | Used in overlays and cards |

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for CDN resources)

### Installation
1. Clone or download this repository
2. Open `index.html` in your browser
3. No build tools or server required!

### File Structure
```
Pasacao Academy/
├── index.html          # Main HTML page
├── css/
│   └── style.css       # Custom styles
├── js/
│   └── script.js       # JavaScript functionality
└── README.md           # Documentation
```
